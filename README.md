# pm-tools

Marketplace плагінів Claude для project-менеджерів.

## Плагіни

| Плагін | Що робить |
| --- | --- |
| [workbook-assistant](plugins/workbook-assistant/README.md) | Помічник PM для роботи з воркбуком проєкту: intake з Upwork, бізнес-аналіз клієнта, тон листів клієнту |

## Встановлення

- **Claude Desktop:** Customize → Plugins → Discover → `+` → `SakhnoDima/pm-tools`.
- **Claude Code:** `/plugin marketplace add SakhnoDima/pm-tools`

Як встановити й налаштувати конкретний плагін, дивись у його README.
